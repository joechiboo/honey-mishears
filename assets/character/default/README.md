# AI 角色圖放這裡

一個姿勢一張**去背 PNG**，檔名就是姿勢名稱。六張到齊後程式會自動改用圖片角色，
不必改任何程式碼。

| 檔名 | 姿勢 | 畫什麼 |
|---|---|---|
| `idle.png` | 待機 | 站著微笑，雙手自然垂放 |
| `listening.png` | 聆聽 | 身體微微前傾、眼睛睜大，一手靠近耳邊 |
| `clean.png` | 打掃 | 袖子捲起、手拿掃把（灰塵特效由程式疊上去，不用畫） |
| `lottery.png` | 報明牌 | 戴墨鏡、抱胸自信（號碼卡由程式疊上去，不用畫） |
| `mask.png` | 敷泥膜 | 滿臉綠泥、兩眼蓋小黃瓜片 |
| `confused.png` | 裝傻 | 歪頭、一臉困惑（問號可畫可不畫） |

> ⚠️ 檔名對應的是 `CharacterPose` 的 **enum 名稱**，不是 Rive 的 trigger 名稱。
> 兩者有兩個不一樣：trigger 是 `listen` / `confuse`，但檔名要寫 `listening.png` / `confused.png`。
> 正確檔名以 `test/character_image_asset_test.dart` 為準（改 enum 會讓那支測試紅燈）。

**補圖規則**：可以一張一張補，缺的姿勢會自動退回 `idle.png`。
但 `idle.png` 一定要有，沒有就整組不啟用、退回內建的佔位角色。

## 生圖要注意的

| 項目 | 規格 |
|---|---|
| 尺寸 | 建議 520 × 600（畫面上顯示 260 × 300，取 2x） |
| 背景 | **必須透明**，舞台的粉色光暈在角色底下 |
| 構圖 | 全身或七分身置中，四周留一點邊，不要頂到畫布 |
| 檔案大小 | 單張壓到 300KB 以內（六張就快 2MB，會影響 APK 體積） |

**一致性比畫質重要。** 六張要看起來是同一個人，做法是：

1. 先寫死一段角色設定文字（髮型、髮色、瞳色、服裝、畫風），存起來
2. 六張都貼**同一段**設定，只換動作描述
3. 用同一個 seed、同一張 reference 圖，**六張一次生完**再挑

不要今天生兩張、明天補三張——中間換了模型或 prompt，臉就不是同一個人了。

可以直接複製貼上的六張 prompt 見
[`docs/character_prompts.md`](../../../docs/character_prompts.md)。
